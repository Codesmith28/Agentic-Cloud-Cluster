CLOUDAI DETERMINISTIC WORKFLOW IMAGE
====================================

Pinned testbench image tag:
- cloudai/workflow-deterministic:v1

Image source (repo-owned):
- testbench/workflow-image/Dockerfile
- testbench/workflow-image/workflow.py

Build and preload into worker DinD daemons:
- testbench/scripts/prepare_workflow_images.sh

Supported workflow subcommands
------------------------------
- cpu-light
- cpu-heavy
- memory-heavy
- mixed
- exit-nonzero
- hang
- slow-start

Common arguments
----------------
All subcommands accept:
- --seed <int>               (default: 1337)
- --result-file <path>       (default: /output/workflow-result.json)

Representative examples
-----------------------
# CPU-light profile
workflow cpu-light --iterations 500000 --seed 101

# Memory-heavy profile
workflow memory-heavy --memory-mib 512 --passes 3 --seed 303

# Failure helper profile
workflow exit-nonzero --code 23

Notes
-----
- Workload manifests in testbench/workloads/ use this pinned tag plus
  explicit workflow parameter blocks.
- The worker executor still runs each task in an isolated /output mount,
  so generated result files remain per-task and deterministic.
