CLOUDAI DETERMINISTIC WORKFLOW IMAGE
====================================

Primary image tag: cloudai-benchmark:1
Image source: testbench/workflow-image/
Build script: testbench/scripts/prepare_workflow_images.sh

This benchmark image is built into each worker DinD daemon before workload
submission. It is repo-owned, deterministic, and does not depend on a public
registry once the testbench is up.

SUPPORTED PROFILES
------------------

cpu-light
  Deterministic short CPU task with CSV output.

cpu-heavy
  Deterministic hashing-heavy CPU task with CSV output.

memory-heavy
  Deterministic in-memory allocation and traversal workload with CSV output.

mixed
  Balanced CPU and memory workload with CSV output.

exit-nonzero
  Helper profile for negative-path testing. Exits with a configurable code.

hang
  Helper profile for timeout and recovery tests. Sleeps for a long duration.

slow-start
  Helper profile that delays startup before executing a deterministic cpu-light task.

USAGE EXAMPLES
--------------

cloudai-benchmark cpu-heavy --seed 203 --iterations 12500 --output cpu-heavy-03.csv
cloudai-benchmark memory-heavy --seed 304 --chunks 10 --chunk-kib 512 --passes 5 --output memory-heavy-04.csv
cloudai-benchmark exit-nonzero --code 17 --sleep-ms 250

WORKLOAD MANIFESTS
------------------

testbench/workloads/heterogeneous-smoke.json
  Default mixed benchmark run.

testbench/workloads/deterministic-full.json
  Full 20-task deterministic benchmark suite.

testbench/workloads/failure-helpers.json
  Helper tasks for recovery and failure-path validation.
